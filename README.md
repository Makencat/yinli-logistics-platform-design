成都银犁冷藏物流股份有限公司 · 物流设计大赛参赛项目
深空驾驶舱风格微信小程序演示版

概述
提货预约协同小程序是一套面向仓储配送一体化的轻量级协同方案。通过微信小程序实现多角色同屏操作，覆盖「需求发布 → 预约提货 → 月台派单 → 备货作业 → 提货离场」全链路闭环。

小程序采用深空驾驶舱视觉体系（深蓝渐变背景 + HUD 刻度圆环 + 科技网格与发光线条），提供客户自助查询与员工集中调度双端界面。

架构概览
首页（深空驾驶舱总览）
  └─ 驾驶舱 → 角色选择（客户 / 员工）
        ├─ 客户端：注册/登录 → 客户工作台 → 运输状态预览（仓库、师傅、时间轴）
        └─ 员工端：登录（yuanshen / 5408） → 员工工作台 → 一键通知客户
                     └─ 客户详情：查看完整运输状态、更改仓库地址、挑选运输师傅
核心功能
首页
数据总览看板（协同批次、在库在途、闭环完成）
协同链路可视化（需求发布 → 预约提货 → 月台派单 → 备货作业 → 提货离场）
客户端
自主注册登录（任意账号密码）
个人运输状态预览（货物所在仓库 / 师傅是否已装车、是否已出发、车辆与司机信息、进度时间轴）
站内消息（仅本人调度推送）
员工端
固定账号登录（yuanshen / 5408）
客户账户列表（横条长方形排列，含单量、在途数、未读角标）
「一键通知客户」按钮（向客户推送调度通知）
货物调度详情（查看完整运输状态、更改分配仓库地址、挑选/指派运输师傅）
全量协同消息

设计特色
深空驾驶舱风格：深藏青底 #0a0f1e + 电光蓝/青绿/紫色状态色
无系统导航栏干扰：自定义 nav-bar 组件读取胶囊位置，保证视觉一体化
自绘图标体系：base64 PNG 内联的语义化 SVG 图标，杜绝 emoji/图标字体
统一设计系统：app.wxss 沉淀公共类（.card / .hero / .stat-num / .timeline 等），页面只写语义化 class
